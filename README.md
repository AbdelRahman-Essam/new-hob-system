# New Hope Feed Manager (Django)

تطبيق Django كامل: قاعدة بيانات حقيقية + تسجيل دخول (كلمات المرور مشفّرة عبر نظام Django
الرسمي)، وثلاث مستويات صلاحية للمستخدمين (مشاهدة فقط / تعديل / مدير كامل)، بالإضافة إلى
لوحة تحكم Django الرسمية `/admin/` لمن يحتاج خيارات أكثر تفصيلًا.

## المزايا
- **الشرائح/المناطق، العملاء، وسحوبات العلف** مع حساب تلقائي للإجمالي وموعد استحقاق الـ40 يومًا.
- **لوحة تحكم** تجمع العملاء حسب الحاجة للمتابعة (قريب / مستحق اليوم / متأخر) + إشعارات متصفح.
- **صلاحيات دقيقة**: مشاهدة فقط، تعديل (إضافة/تعديل/حذف البيانات)، أو مدير كامل (يضيف ذلك
  إدارة المستخدمين والإعدادات والنسخ الاحتياطي).
- **إضافة عملاء بالجملة** عبر استيراد ملف CSV (الإعدادات ← العملاء ← استيراد عملاء).
- **تقارير** قابلة للتصفية والطباعة وتصدير CSV.
- **نسخ احتياطي/استعادة** بصيغة JSON من داخل التطبيق.
- واجهة عربية (RTL) متجاوبة: تصميم موبايل بشريط تنقل سفلي، وتصميم كمبيوتر بقائمة جانبية.

## 1) التشغيل محليًا للاختبار
```bash
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser      # أول حساب يُعامَل تلقائيًا كمدير كامل الصلاحيات
python manage.py runserver 0.0.0.0:8000
```
افتح http://localhost:8000

## 2) النشر على سيرفرك (رابط عام حقيقي دائم)
راجع **[DEPLOY.md](DEPLOY.md)** — دليل كامل خطوة بخطوة لسيرفر Ubuntu + Nginx + DuckDNS
(Gunicorn كخدمة systemd، HTTPS مجاني عبر Certbot، نسخ احتياطي تلقائي يومي).

## 3) إدارة المستخدمين والصلاحيات
- كمدير: الإعدادات ← "إدارة المستخدمين" → إضافة مستخدم واختيار صلاحيته:
  - **مشاهدة فقط**: يرى كل شيء، بدون أي زر إضافة/تعديل/حذف.
  - **تعديل**: يضيف/يعدّل/يحذف الشرائح والعملاء والسحوبات لكل العملاء، لكن لا يصل إلى الإعدادات أو المستخدمين.
  - **مندوب**: يرى ويضيف/يعدّل فقط عملاءه هو (لا يرى عملاء غيره، ولا يدير الشرائح).
  - **عميل**: يرى فقط بياناته وسجل سحوباته الخاص (بدون أي تعديل).
  - **مدير كامل الصلاحيات**: كل شيء، ويصل أيضًا تلقائيًا إلى `/admin/`.
- أول حساب تنشئه بـ `createsuperuser` هو دائمًا مدير كامل الصلاحيات بغض النظر عن أي إعداد آخر.
- **ربط مندوب أو عميل ببياناته الفعلية**: بعد إنشاء المستخدم بصلاحية "مندوب" أو "عميل"، افتح صفحة العميل
  المطلوب (العملاء ← اختر العميل ← تعديل) واختر "المندوب المسؤول" و/أو "حساب دخول العميل" من هناك.
  عميل واحد قد يكون له مندوب واحد فقط، وحساب عميل واحد يُربط بعميل واحد فقط.
- عند إنشاء عميل جديد بواسطة مندوب نفسه، يُربط تلقائيًا بذلك المندوب.

## أشياء أخرى
- الشعار: `feed/static/feed/new_hope_logo.jpg`
- اسم التطبيق / بيانات التواصل: `config/settings.py`
- الاختبارات: `python manage.py test`

## تنبيه أمان
- غيّر `SECRET_KEY` قبل النشر الفعلي (موجود في `/etc/newhope.env` على السيرفر، راجع DEPLOY.md).
- استخدم HTTPS دائمًا في الإنتاج (خطوة Certbot في DEPLOY.md) حتى لا تُرسل كلمات المرور نصًا واضحًا.
