# New Hope Feed Manager (Django) — نسخة أونلاين حقيقية بتسجيل دخول

هذه نسخة Django كاملة: قاعدة بيانات حقيقية + تسجيل دخول باسم مستخدم وكلمة مرور
(نظام Django الرسمي للمصادقة، كلمات المرور مشفّرة بشكل صحيح وليست نصًا واضحًا)،
والمدير (is_staff) يمكنه إضافة/تعديل/حذف حسابات المستخدمين من داخل التطبيق نفسه
(الإعدادات ← المستخدمون)، بالإضافة إلى /admin/.

**مهم جدًا:** حتى يفتح "عملاء/عمال بدون حساب Claude" هذا التطبيق من الرابط، يجب
رفعه (Deploy) على سيرفر له عنوان على الإنترنت. تشغيله على جهازك فقط
(runserver) يجعله يعمل على شبكة الواي فاي المحلية فقط، وليس رابطًا عامًا يمكن
إرساله لأي شخص. لا أملك اتصالًا بالإنترنت هنا لأرفعه لك، لذا هذه خطوات الرفع
بنفسك على استضافة مجانية بسيطة.

## 1) التشغيل محليًا للاختبار
    python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
    pip install -r requirements.txt
    python manage.py migrate
    python manage.py createsuperuser      # أنشئ أول حساب مدير هنا (اسم مستخدم + كلمة مرور)
    python manage.py runserver 0.0.0.0:8000
افتح http://localhost:8000 — سيطلب تسجيل الدخول بالحساب الذي أنشأته.

## 2) رفعه على الإنترنت (رابط عام حقيقي)
أبسط خيار مجاني بدون بطاقة ائتمان: **PythonAnywhere**.
1. أنشئ حسابًا مجانيًا على pythonanywhere.com.
2. ارفع مجلد المشروع (Files) أو استخدم Git.
3. من Web tab: أنشئ Web App جديد، اختر Manual configuration → Python 3.
4. عدّل ملف WSGI ليشير إلى `config.wsgi.application`، وثبّت `pip install -r requirements.txt` من Bash console هناك.
5. شغّل `python manage.py migrate` و`python manage.py createsuperuser` من نفس الـ Bash console.
6. عدّل `config/settings.py`: ضع `DEBUG=0` وأضف نطاق الموقع إلى `ALLOWED_HOSTS`
   (مثال: `["yourname.pythonanywhere.com"]`).
7. اضغط Reload — رابطك سيكون مثل: `https://yourname.pythonanywhere.com`
هذا الرابط هو ما ترسله لأي شخص (عميل أو عامل)، وسيرى فقط شاشة تسجيل الدخول.

بدائل أخرى مشابهة (تحتاج بطاقة للتحقق أحيانًا): Render.com، Railway.app.

## 3) إدارة المستخدمين (بدون Claude، حسابات داخل تطبيقك فقط)
- كمدير (is_staff): الإعدادات ← "إدارة المستخدمين" → إضافة مستخدم جديد
  (اسم مستخدم + كلمة مرور + هل هو مدير أم لا).
- كل عامل/عميل يدخل باسم المستخدم وكلمة المرور التي أعطيته إياها أنت — لا يحتاج أي حساب Claude أو بريد إلكتروني.
- يمكنك أيضًا إدارتهم من /admin/ إن أردت خيارات أكثر تفصيلًا (مثل صلاحيات دقيقة).

## أشياء أخرى
- الشعار: `feed/static/feed/new_hope_logo.jpg`
- اسم التطبيق / بيانات التواصل: `config/settings.py`
- نسخة احتياطية: الإعدادات ← تحميل نسخة احتياطية (JSON)، أو ببساطة انسخ ملف `db.sqlite3`.
- الاختبارات: `python manage.py test` (تتحقق من حساب الـ40 يومًا، الإجمالي، الحذف المتسلسل...).

## تنبيه أمان
- غيّر `SECRET_KEY` في `config/settings.py` (أو استخدم متغير بيئة) قبل النشر الفعلي.
- استخدم HTTPS (الاستضافات المذكورة توفره تلقائيًا) حتى لا تُرسل كلمات المرور نصًا واضحًا عبر الشبكة.
